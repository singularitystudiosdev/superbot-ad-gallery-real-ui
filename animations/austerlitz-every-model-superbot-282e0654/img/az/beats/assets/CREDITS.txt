Every file here is one real frame of the film AUSTERLITZ (WinterArc21/Battle-of-Austerlitz-Film, main @ 86dae32d),
cropped and lanczos-resized. Nothing was drawn, painted, graded or generated.
  source   /tmp/austerlitz.282e0654/A/austerlitz-master.mp4, the repo master video/austerlitz.mp4
           (1920 x 1080, 24 fps, 7232 frames, 301.333 s)
  frames   cut with ffmpeg -ss n/24 -i austerlitz-master.mp4 -frames:v 1 (checked pixel-identical to
           ffmpeg -vf "select=eq(n\,3504)" for n = 3504: zero difference)
  crops    x, y, w, h in 1920 x 1080 source pixels, all inside the picture band (rows 131..948) and all outside the
           film's caption windows (Telnitz 139.75-144.58, The Pratzen Heights 152.33-157.42, The Russian Imperial
           Guard 204.46-208.50, Rapp's charge 215.21-219.42, The Satschan ponds 239.33-243.83), so no caption text
  output   400 x 225 JPEG (quality 86, lanczos), shown about 100 x 56 in the card's tiles
  names    each file is named for the sprite the film draws in it, from web/engine/sprites.js @86dae32d
           (reg() calls, lines 520-594); the scene's formation is in web/film.js @86dae32d
