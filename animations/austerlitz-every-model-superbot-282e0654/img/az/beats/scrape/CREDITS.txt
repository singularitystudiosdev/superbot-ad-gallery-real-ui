terrarium-z13-mosaic.png (280 x 280 px)
  The 49 AWS Terrarium elevation tiles that tools/fetch_terrain.py in
  https://github.com/WinterArc21/Battle-of-Austerlitz-Film fetches for its bbox
  (LAT 49.060 to 49.215, LON 16.630 to 16.900, zoom 13): x 4474 to 4480, y 2805 to 2811.
  Downloaded 2026-09-27 from the same URL template the script uses, every tile HTTP 200,
  256 x 256 RGB each. Laid out 7 x 7 (x across, y down) and resampled nearest-neighbour
  from 256 to 40 px per tile, so every pixel is an unaltered encoded sample
  (height = R * 256 + G + B / 256 - 32768 m). No colour change in the file; scrape.css
  shows it under a CSS grade (sepia .55, saturate .7, brightness .82, contrast 1.05) so the
  raw red and green sit in the film's night palette.
  Source: Mapzen/Tilezen Terrarium on the AWS Open Data registry (elevation-tiles-prod),
  built from SRTM and other public DEMs; terms: https://github.com/tilezen/joerd/blob/master/docs/attribution.md
  Numbers read off these tiles for the card: the bbox spans 19.66 x 17.14 km
  (fetch_terrain.py's own formula), 512 samples across = 38.4 m grid, heights inside
  the bbox 178 to 388 m.
