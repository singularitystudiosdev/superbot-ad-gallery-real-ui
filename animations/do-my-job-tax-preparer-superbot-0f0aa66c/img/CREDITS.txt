Nothing else in this folder is third-party. The ProConnect desk is not an image: it is rebuilt in HTML/CSS/SVG in
../scenes/tabs-assets/proconnect.{js,css}. Its colours, type sizes, radii and chrome sizes are measured from Intuit's own
lossless captures of the 2025 app (the Navattic demo above), the "ProConnect Tax Online: The Fundamentals" webinar
(https://www.youtube.com/watch?v=vNULxPT9Ifc, Intuit Accountants channel) and Intuit help-article images; every value is a
custom property in ../scenes/tabs-assets/proconnect.tokens.css, with the pixel it was sampled from. The reference pack
itself stays outside the repo (.tmp/tp-uiref.0f0aa66c in the pipeline project). No screenshot is embedded in the ad. The
nav, toolbar and tab icons are hand-drawn SVG, not Intuit's icon files. The desk's wording is the product's own (2025
generation): the tabs Profile / SmartReturn / Input return / Check return / File return, the return-type card "1040
Individual" with Rejected / Not e-filed / Transmitted / Accepted, the columns FEDERAL EFILE STATUS / STATE EFILE STATUS /
EXTENSION EFILE STATUS, the diagnostics headings Fatal Diagnostics / EF Critical Diagnostics / Suggestions, the e-file statuses Received
by Intuit / Received by agency / Accepted / Rejected (https://accountants.intuit.com/support/en-us/help-article/electronic-filing/e-file-status-descriptions-proconnect/L7kP5XGRA_US_en_US)
and the rejected acknowledgement's "Error message: / Solution: / Code:".

No person is named anywhere in the spot and no client is invented. Returns are identified by their situation only (for
example "Tips paid through a 1099-K platform", "Prior-year AGI rejected (IND-031-04)"); no SSN, EIN, PTIN, EFIN,
submission ID or Intuit reference number is shown. The Intuit demo's own sample data is not used. The firm slot reads
"Your firm" and the signed-in user is a generic avatar. The three answered returns are the IRS and Treasury worked
examples themselves (none of which names a person). The client emails and drafted replies are the ad's own copy, written
as plain restatements of the sourced facts below and nothing beyond them. Text in quotation marks on the answer card, and
every "Error message" line, is verbatim from the named source. Every count on screen is the literal number of items on
screen (12 extended returns, 6 of them rejected, 14 past returns, 4 fixes learned). Two values are not from a source: the
ad's clock, Tue Sep 29, 2026 (the acknowledgement date 09/29/2026), and "16 days left" to Oct 15, 2026 (calendar
arithmetic from that clock). Weekdays are calendar arithmetic.
