UI            Every app frame is DOM and CSS from the superbot-desktop renderer, main @366230a
              (2026-10-05). The app was booted from a clean clone with its e2e edge stub, the three
              asks were typed into its real composer, and each state was snapshotted (outerHTML,
              stylesheets, scroll offsets) at four window shapes: 1440x810, 1080x810, 810x810 and
              648x810 CSS px, one per aspect ratio. states.<ratio>.js hold those snapshots, deduped
              by subtree; app.css is the renderer's own stylesheet text, pruned to the rules the
              snapshots match; app/ holds the renderer's own fonts (Inter, re-encoded to woff2)
              and icons.
