# superbot — "favorite color"

A 16:9 programmatic ad spot: a ChatGPT-lookalike screen where a model
overthinks "whats ur favorite color", the camera flies down the wall of
text it types, and superbot answers "Black." — stop burning tokens.

Fully deterministic and seekable: every frame is computed from `t`.
- open `index.html` — plays on loop
- `index.html?t=12.4` — freeze-frame at any time; arrow keys step ±0.25s
- `variants.html` — side-by-side treatments (`?emph=`, `?fly=`, `?delay=`)
- Record exports a 1920×1080 webm

Play at https://singularitystudiosdev.github.io/superbot-favorite-color/
