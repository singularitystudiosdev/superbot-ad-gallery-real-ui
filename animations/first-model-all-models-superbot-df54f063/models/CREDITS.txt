3D models for the "Meshy" beat
==============================

All four models come from the ride demo's own procedural geometry:

  Source repo : https://github.com/StarKnightt/summer-cycle  (commit 8b977baad061e797c2f6c19cfcf07c1e79b23a67)
  Author      : Prasenjit (GitHub: StarKnightt)

How they were produced (same for every file)
  - A small Vite entry (/tmp/summer-cycle/export/export.ts, driven by /tmp/summer-cycle/export/run.mjs)
    imported the repo's own factory functions and built each object in headless Chromium (Playwright,
    SwiftShader WebGL), using the three.js version the repo installs (three r186).
  - The repo's custom "uber" toon ShaderMaterial was baked to plain MeshStandardMaterial
    (roughness 0.8, metalness 0). Flat-coloured triangles became one material per source colour;
    triangles carrying a colour gradient keep the source vertex colours (COLOR_0).
  - World transforms applied; each object stands on y=0, centred on x/z, Y up, units in metres.
  - Exported with three's GLTFExporter (binary: true). No Draco/meshopt, no external files.

bike.glb - bicycle with the rider seated on it in riding pose (one object)
  Source files : src/rider/rider.ts (class Rider, which builds and owns src/rider/bike.ts class Bike)
  Notes        : Rider.update() run for 90 frames with a riding state (pedalling, crank 0.35 rad,
                 no steer/lean) to settle the pose. Omitted: the blob ground shadow, the near-invisible
                 glasses lenses and the soft gradient face decals (blush/shading); the solid painted
                 eye layers are kept.

torii.glb - red torii gate
  Source file  : src/world/street.ts, function shrine()
  Notes        : shrine() returns the torii together with stone steps and a hokora behind it; only the
                 torii triangles (|z| < 0.5 m) were kept. The name plaque uses a canvas sign atlas in the
                 ride; here it is painted plain dark (#2a2624) instead of textured.

tree.glb - broadleaf tree (the ride's "round" camphor/keyaki-like tree, seed 7, hero LOD 0)
  Source file  : src/world/props.ts, function tree("round", 7, 0)
  Notes        : The ride's leaf-cluster cards use a canvas-painted leaf atlas (src/render/leafAtlas.ts);
                 it is embedded as one 512x512 PNG (grey tone + alpha, alphaTest 0.5). The foliage shader's
                 sunlit-canopy lift (toward #4f7d3a on up-facing leaves) was baked into the vertex colours.
                 Trunk bottom (sunk 0.3 m below ground in the ride) clamped to y=0.

lantern.glb - stone lantern (ishi-doro / toro)
  Source file  : src/world/street.ts, function stoneLantern()
