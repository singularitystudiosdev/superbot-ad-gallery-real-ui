triangle count and a signed geometry URL (quadJsonUrl) holding vertices plus quad face indices. All four are CC0 1.0
(public domain dedication, no attribution required). The authors are named anyway so the source is on the record:

THE RENDERS. meshy.js names the triangle count printed on each badge from the model record above: those are the
meshes' published counts, not decoration. Frames are 448x320 webp, 36 per revolution, written by
canvas.toDataURL('image/webp', 0.92) inside headless Chrome (--use-angle=swiftshader), lit by meshy's own viewport
recipe: a soft key from the upper front right, a cool rim behind, a low fill, a dark background and a faint grid
floor. The clay pass is a plain grey standard material; the wireframe pass the same shell with a lime wire overlay;
the textured pass an authored PBR material per subject (colours, metalness and roughness are recorded in the header
of beats/meshy.js), tinted with the ad's ink lime: juno 0x93dd24 / 30% lime, the palm split by height into bark brown
and leaf green / 10% and 26%, the crate 0x8a5a2b / 14%, the billboard steel 0x7b8087 / 16%. The lime is the ad's own
ink colour, not a colour any of the meshes carries; it is named on the "Ink Lime" swatch in the viewport.

NO API KEY. No Meshy account, key or credit was used: the showcase feed and the geometry URLs it signs are public
reads. The rule this spot ships under (no hand-drawn or generated imagery) holds for every file here.
