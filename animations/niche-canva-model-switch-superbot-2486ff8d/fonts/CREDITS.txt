noto-sans-latin-{400,600}-normal.woff2
  Noto Sans, latin subset, from @fontsource/noto-sans 5.3.0
  (https://cdn.jsdelivr.net/npm/@fontsource/noto-sans/files/noto-sans-latin-<weight>-normal.woff2), fetched 2026-10-03,
  unmodified. Copyright 2022 The Noto Project Authors (https://github.com/notofonts/latin-greek-cyrillic).
  Licence: SIL Open Font License 1.1 (https://openfontlicense.org).
  Used for the Canva window's UI (scenes/tabs-assets/beats/canva.css @font-face "Noto Sans CV").
  Why this face: Canva's UI face is Canva Sans, which is proprietary and is NOT bundled here. The closest OFL
  substitute we can justify from a first-party source is Noto Sans: Canva's own App UI Kit
  (@canva/app-ui-kit 5.14.3, dist/styles.ltr.css) declares the stack "Canva Sans", "IBM Plex Sans Arabic",
  "Noto Sans Variable", "Noto Sans", -apple-system, ..., so Noto Sans is the face Canva itself falls back to when
  Canva Sans is unavailable. Only the two weights the window uses (400, 600) are vendored, so nothing is fetched at render.

Fraunces and Inter (the client's brand fonts, both SIL OFL 1.1) appear only baked into the design JPGs under img/
(see img/CREDITS.txt); the live page does not use them, so they are not shipped.
The superbot hub keeps the source ad's families.
