  Teachable baking course, plus "Crumb & Crust" bakery baking classes, returned no school, course or bakery of that
  name (only unrelated "Crumb" businesses), so the brief's first name stands.
  Facts checked against Teachable's own help center (support.teachable.com, retrieved 2026-10-03):
  - Terms: courses are "divided into sections and lessons"; the UI says "New lesson", "New section", "Bulk upload",
    "Bulk edit", "Quick actions", "Preview" (/en/articles/11682453-sections-and-lessons). A quiz is a Quiz block inside
    a lesson (/en/articles/11682455-add-lesson-content), so each section's quiz is a lesson row ("Section 1 quiz") and
    the sections read "5 lessons, 1 quiz"; the 24 lessons are the teaching lessons.
  - Status: a course is Published or Unpublished, "Publish course" / "Unpublish course"
    (/en/articles/11682484-publishing-and-product-visibility); there is no "Draft" course status, so the badge flips
    UNPUBLISHED to PUBLISHED (the brief said Draft "or whatever the sources show"). Lessons are unpublished by default
    and each has its own Publish / Published button (11682453), so every lesson flips with the course.
  - Layout: inside a course the admin shows the dark icon rail, the course card, the Setup guide pill and the course
    sub-nav Curriculum, Design templates, Certificates, Information | Pricing, Sales pages, Embed, Coupons, Upsell funnel
    | Comments, Students, Reports; the page header is the "Courses | <course>" breadcrumb, a serif heading, an uppercase
    status badge, and white outline buttons (2025-11-03 captures in /en/articles/11682451-create-and-set-up-your-course;
    the curriculum rows, section cards, Publish buttons and dark toasts in the 11682453 captures).
  - Course image: 16:9 (/en/articles/11682492-image-size-guide: product thumbnail 1024 x 576).
  - Enroll button: "Enroll now" is the current product page string (u.teachable.com product page i18n, buy_now);
    "Enroll in Course" is the Page Editor 1.0 default (/en/articles/11682518-page-blocks-page-editor-1-0).
  - Connect: Teachable documents no third-party app consent screen, so the sheet keeps the brief's "Connect" in
    teachable.com's own button styles (.button-primary-new lemon with black label, .button-secondary white).
