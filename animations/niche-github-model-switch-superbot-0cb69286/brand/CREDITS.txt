GITHUB'S AUTHORIZE-PAGE WORDING (sources of record)
  The authorize card follows github.com/login/oauth/authorize. The permission rows name the two scopes superbot asks
  for, in GitHub's own words:
  - repo: row "Repositories" (the data type named in "Authorizing OAuth apps",
    https://docs.github.com/en/apps/oauth-apps/using-oauth-apps/authorizing-oauth-apps, fetched 2026-10-03:
    "Repositories ... Apps can request access for either public or private repositories"), detail "Public and
    private" (the repo scope "Grants full access to public and private repositories", Scopes for OAuth apps,
    https://docs.github.com/en/apps/oauth-apps/building-oauth-apps/scopes-for-oauth-apps, fetched 2026-10-03).
  - workflow: row "Workflow", detail "Add and update GitHub Actions workflow files" (the workflow scope "Grants the
    ability to add and update GitHub Actions workflow files", same page).
  The live authorize page itself is behind a login, so its exact row strings could not be fetched; the rows above are
  the docs' wording. Neither string contains a dash, so no line was split.
