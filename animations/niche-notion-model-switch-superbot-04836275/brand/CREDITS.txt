NOTION BOARD, SIDEBAR AND PALETTE (sources of record)
  Board: Notion help "Board view (Kanban)", https://www.notion.com/help/boards (fetched 2026-10-03): boards "can be
  grouped by status, assignee, priority"; group by another property from the settings menu; "large, medium, or small
  card sizes"; "To the immediate right of each column heading, you'll see a gray number ... the number of cards in
  each column". Empty group label: Notion names the empty group "No <property>" (seen live on the measured page: its
  board's empty Status group reads "No Status"), so the empty Owner group is "No Owner". Date format: the measured
  page's date properties read "May 11, 2025" (Notion's default full date, month day, year), so Due reads e.g.
  "October 9, 2026"; only May dates were on the page, so the spelled-out long month name follows the same format and
  was not seen for a long month. Status: "Not started" is Notion's default status option (help "Database properties",
  https://www.notion.com/help/database-properties: status tags in To-do, In Progress and Complete groups); its chip
  colours (gray rgba(28,19,1,.11), text #494846, 9px radius, dot) were measured live on a "Not started" chip. Sidebar:
  Notion help "Navigate with the sidebar", https://www.notion.com/help/navigate-with-the-sidebar (fetched 2026-10-03):
  the workspace switcher, Search, Home, Chats with Notion AI, Meetings, Inbox, Library, and the Teamspaces / Shared /
  Private sections.

  board page, https://linnon-lab.notion.site/color-coded-task-management-board (Notion web 23.13.20261003.0412, light
  theme, 2026-10-03), and the page title / body type on
  https://notion.notion.site/Getting-started-with-Projects-Tasks-Sprints-b9bc1775be334046a46c38149362a978 (40px/48px
