  Source: Microsoft Graph permissions reference, https://learn.microsoft.com/en-us/graph/permissions-reference
  (fetched 2026-10-03), the Delegated column of each permission's table, row "DisplayText", quoted exactly:
    Files.ReadWrite (delegated id 5c28f0bf-8a70-41f1-8ab2-9032436ddb65): "Have full access to user files"
    User.Read       (delegated id e1fe6dd8-ba31-4d61-89e7-88639da4683d): "Sign in and read user profile"
  The card is superbot's own (dark hub card); it is not a copy of Microsoft's sign-in or consent page and carries no
  Accept / Cancel / Deny / Allow buttons: "Access granted" lands as a status row.

EXCEL FOR THE WEB (the framed window)
  A spreadsheet grid only: column letters A to F, row numbers, gridlines, the selected cell's green border and lit
  headers, the Name Box and the fx formula bar. No ribbon, toolbar, Share / Comments / Editing, sheet tabs, + button,
  avatars, fill handle or cancel / enter glyphs. Palette: white cells, #e1e1e1 gridlines, #f5f5f5 headers with #616161
  labels, Excel green #107c41 for the selection, red #c42b1c for errors and nonzero variances.
