YOUTUBE STUDIO UI (sources of record)
  Layout, labels and dark palette: 2026 YouTube Studio screenshots in vidIQ's "How to Use YouTube Studio" guide
  (https://vidiq.com/blog/post/beginners-guide-youtube-studio/, fetched 2026-10-06): the header (Inspiration, help,
  notifications, "Ask Studio", "Create", avatar), the channel menu labels (Community, Languages, Content detection,
  Earn, Customization), the video menu (Channel content, Your video, Details, Analytics, Editor, Comments, Languages,
  Earn, Claims, Clips), the Comments page grammar (Published / Most relevant / Search chips, the "Comment" header row,
  checkbox + avatar + @handle + age + subscriber badge, Reply pill, replies toggle, like / dislike / heart / more,
  reply-suggestion chips). Colours sampled from those PNGs: page #0f0f0f, filled surfaces #2e2e2e, rules #4a4a4a.
  Behaviour: YouTube Help "Review & reply to comments" https://support.google.com/youtube/answer/9482367 (fetched
  2026-10-06): Pin "only appears when viewing comments for an individual video", hence the video's own Comments page.
  The YouTube Data API v3 has no pin call: https://developers.google.com/youtube/v3/docs/comments (fetched 2026-10-06)
  lists only list, insert (replies), update, delete and setModerationStatus, which is why superbot pins by hand in Studio.
