The routing (why each switch)
  The chain follows the superbot edge's media routing table (new-superbot-hero-animation
  adapters/media-capabilities.ts), each step handing the next its input:
  1. pocketsflow.com (a service switch): the brand is read first (homepage, pricing), saved as brand notes.
  2. Gemini 3.1 Flash Image (image lane, gemini-3.1-flash-image; Google's Nano Banana 2, documented for
     multi-reference image consistency at ai.google.dev/gemini-api/docs/image-generation, 2026-10-07): the site's
     mascot kept on-model as one still. The label is the edge's own modelLabel for that id (adapters/media-lane.ts).
  3. Veo 3.1 (video lane, veo-3.1-generate-preview): that still as its reference image, animated into the
     opening shot, with room left for the title the cut adds.
  4. Eleven Music v2.5 (music lane; music_v2_5 per elevenlabs.io/docs/api-reference/music/compose, 2026-10-07).
     The table leaves the music model to the vendor; the label names the current one.
  5. Claude Opus 5.5 (code): the Remotion composition, cut to the score, with the titles, and the render.
  An earlier cut used Meshy (3D) between 1 and 3; the audit dropped it because nothing downstream can consume a
  GLB (Veo takes text and images).
