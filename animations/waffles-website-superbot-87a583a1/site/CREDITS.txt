Waffle Rank image credits
=======================

All ten photos come from Wikimedia Commons. Each one was downloaded at 1100 pixels
wide and saved as a JPEG in site/img, so the files here are resized copies of the
originals. The author and license of every file are listed below, together with a
link to the license text and to the Commons file page where the original lives.

Photo files are used only to show what a rated waffle looks like. If you reuse the
site, keep this file with it: CC BY and CC BY-SA both require attribution, and the
CC BY-SA photos also require that any adaptation you publish carries the same
license.
